# 새 땅 — 게임 상태판 시제품

Claude Code 채팅 옆에 게임 상태판을 띄워 보는 시제품입니다. 실제 게임 엔진과는 아직 이어져 있지 않고,
미리 넣어 둔 견본 장면 네 개(전투 시작 → 재기와 첫 적 처치 → 다음 라운드 → 승리)를 차례로 보여 줍니다.

- **게임 폴더에서만 켜집니다.** 작업 폴더에 `trpg-game.json` 파일이 있을 때만 패널과 띠가 보이고, 다른 폴더의 세션에는 아무것도 나타나지 않습니다.
- 게임 폴더에서는 채팅 옆에 「새 땅」 패널이 열리고, 입력창 위에 한 줄 띠가 생깁니다.
- `/trpg-demo`를 칠 때마다 다음 장면으로 넘어갑니다.
- `/trpg-panel`은 닫힌 패널을 다시 엽니다.

패널이 놓이는 자리는 Claude Code를 여는 화면(데스크톱 앱, 터미널, VS Code)에 따라 다릅니다.
클라우드에서 도는 세션에는 패널 자리가 없어 보이지 않습니다.
